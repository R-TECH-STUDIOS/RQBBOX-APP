# RQBBOX-APP

RQBBOX 1.0 is a gaming-console-like web dashboard concept inspired by modern Xbox and PS5 UI systems, co-branded with RTECH.

## Experience Highlights
- RQBBOX × RTECH branded boot-up splash with live progress status
- RQBBOX × RTECH ID Login / Sign Up access portal
- Console OS layout with sidebar navigation, top action bar, and profile card
- Featured hero mission panel with real-time performance telemetry (FPS, ping, GPU temp)
- Interactive dashboard controls with in-app toast feedback (all buttons wired)
- Dynamic "Up Next" queue to simulate a next-gen game launcher flow
- Responsive behavior for desktop and tablet/mobile widths

## Run locally
```bash
python3 -m http.server 4173
```
Then open: <http://localhost:4173>
